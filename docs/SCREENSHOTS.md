# Screenshot Checklist

1. Laptop specifications — show output of system info commands (manufacturer, model, CPU, RAM)
2. Windows version — `winver` or systeminfo
3. Internet speed test — speedtest-cli or browser screenshot
4. WSL status — `wsl -l -v`
5. Docker version — `docker --version` and Docker Desktop UI
6. Docker Compose / compose.yaml — show file and command output
7. Project structure in VS Code — show workspace tree
8. Docker image build — `docker compose build` output
9. Running containers — `docker compose ps`
10. AI Personal Assistant interface — UI page showing assistant
11. AI conversation — active chat with assistant reply visible
12. Assistant tool execution — any API response shown
13. Database data — connect to Postgres and show rows (psql or admin UI)
14. Docker logs — `docker compose logs backend`
15. Final working system — combined UI + running containers

For each screenshot, ensure the command and its output are visible, the timestamp is legible, and sensitive data (API keys) are hidden.
